# Horse Flute Anywhere

### Summon your horse from anywhere in Stardew Valley

Horse Flute Anywhere removes the limitation that prevents you from using the horse flute in buildings and mines. Summon your horse whenever and wherever you need it for faster travel across the entire game world.

<br>

---

## Features

| | |
|:---|:---|
| **No Restrictions** | Use the horse flute in mines, caves, festival areas, and buildings |
| **Instant Summon** | No more running to the stable — your horse comes to you |
| **SMAPI Compatible** | Plays nicely with other mods that modify travel or the horse |
| **Simple & Lightweight** | Tiny mod with a single purpose — does one thing perfectly |
